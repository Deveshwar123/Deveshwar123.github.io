clipflow privacy policy

Last updated 13 November 2026

clipflow is a personal tool built and run by Deveshwar Vankeswaram. It finds Creative Commons videos on YouTube, cuts them into short vertical clips with credit to the original creator, and publishes those clips to his own YouTube channel. It is not offered to the public, and it is used only by its author.

What clipflow uses YouTube API Services for

clipflow uses YouTube API Services. By using clipflow you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

  • Search and read public video information. Titles, channel names, view counts, durations and licence type are used to rank Creative Commons videos.
  • Upload videos to the signed-in account's own channel.
  • Read view, like and comment counts for videos clipflow uploaded, to show which clips perform best.

What data is stored, and where

  • The OAuth token for the signed-in account, stored only on the author's own computer, readable only by his user account.
  • A local database of which public videos were used, which clips were made, and their upload IDs and view counts.

clipflow has no server. It does not collect, sell or share any personal data, and it does not send YouTube data to anyone else. It does not access data from any account other than the one that signs in.

Keeping and deleting data

Stats are refreshed at most once a day and kept only as long as clipflow is in use. Deleting clipflow's local folder removes all stored data. You can revoke clipflow's access at any time from Google account permissions, which also invalidates the stored token.
